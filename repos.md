## 1. get-shit-done
**URL:** https://github.com/gsd-build/get-shit-done
**Category:** AI Development Workflow / Context Engineering
**Stars:** N/A

### Description
A lightweight and powerful meta-prompting, context engineering, and spec-driven development system designed for Claude Code and other AI coding assistants.

### Purpose
Solves "context rot" — quality degradation as AI assistants fill their context window — by providing structured workflows for planning and executing software projects through AI agents.

### Key Features
- Spec-driven development with XML-formatted prompts
- Structured workflow: discuss → plan → execute → verify → ship
- Parallel task execution with atomic git commits
- Multi-agent orchestration for research, planning, and verification
- Compatible with Claude Code, OpenCode, Gemini CLI, Codex, Copilot, and Antigravity
- Cross-platform: Mac, Windows, Linux

### Topics
`meta-prompting` `context-engineering` `spec-driven-development` `ai-coding` `claude-code` `workflow-automation`
